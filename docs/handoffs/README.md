# Handoffs

A handoff is the build instructions for one issue. It is written so someone
with no memory of the conversation can carry the issue out as decided.

The builder follows it. Steps marked as the owner's stay with the owner. A
handoff marked **Ready** can be executed. A **Draft** is blocked and must
not be executed.

Plans stay the record of how a feature was designed. A handoff is the record
of how one issue was handed to a builder.
